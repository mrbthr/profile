# Security policy

This Website is hosted via GitHub Pages, a service provided by GitHub, Inc.
When you access the Website, GitHub's infrastructure automatically records standard technical telemetry in server logs to ensure network security, prevent abuse, and maintain service availability.
This data may include:

• Internet Protocol (IP) address
• Browser type, version, and language settings
• Operating system and device type
• Referring URL and exit pages
• Date, time, and duration of access

Mar. Andre do not have direct access to raw server logs containing identifiable IP addresses, nor do we use this infrastructure data to profile individual visitors.
For further details, please consult the GitHub General Privacy Statement.
